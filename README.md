# CyberLab

CyberLab is my personal project for learning Linux administration and virtualization.

The project uses KVM/QEMU and libvirt to create and manage virtual machines. I use Bash scripts to automate tasks such as creating QCOW2 images, configuring virtual machines and removing unused resources.

## Technologies

- Linux
- KVM/QEMU
- libvirt
- Bash
- SSH
- QCOW2
- Linux bridge
- Git

## Status

The project is still in development. I am currently improving the scripts and documentation.
